## 公司業務與品牌故事

- 公司：Orai service
- 品牌故事與理念：受創新科技與在地文化的啟發，Orai Service 專注於語音交互的溫度與實用性。致力為香港及本地中小企無痛部署企業級 AI 語音服務，打破技術門檻與高昂開發成本。讓每個團隊都能擁有全天候 24/7 精通廣東話、普通話及英語的智能前台與導航助手，釋放人手專注於核心業務增長，用更低門檻、更高效率迎戰數碼轉型。我們相信 AI 不應該只是大企業的專利，Orai Service 希望成為本地中小企最可靠的數碼拍檔，幫企業省下時間與人力成本，把精力留給業務增長與客戶關係。
- 核心方案價值：
  1. 聽得明地道語言：流暢支援廣東話、英語及普通話混合溝通，像真人前線員工一樣自然應對。
  2. 真真正正幫到手：由 24/7 自動解答查詢、引導訪客瀏覽網頁，到即時收集預約與報價資料，幫企業留住每一個潛在商機。
  3. 無痛部署，快速見效：無需自建 IT 團隊，短短數週即可將專屬 AI 助理無縫接入現有網站。
- 業務：香港本土研發企業級三語 AI 語音網頁導航與企業私有知識庫方案。三語係廣東話、普通話、英文。
- 安裝：現有網站加一行 script 就嵌入到。
- 知識庫：管理員可以喺後台上傳企業專屬 PDF、價目表同服務條款。AI 嚴格依照上傳檔案回答，唔會憑空作答。
- 導航：識聽聲，自動帶訪客跳頁同預約。

## 收費

核心基礎部署方案（Core Voice Engine），沒有固定月費：

1. 一次性基礎設定費：HK$8,000 起（視乎企業知識庫 PDF 及網站資料規模與複雜程度而定）。
2. 每月平台與流量費：按實際通話流量（分鐘）彈性計費。用幾多計幾多，設有 80% 及 100% 用量自動提醒，絕無隱藏月費。按年預繳可享 9 折。

基礎方案已包含即時真人語音對答（地道廣東話，可按需配置雙語或三語）、企業私有知識庫（以企業提供資料為依據，遇到不確定問題轉交真人）、1 行 script 掛載，以及管理員後台與通話紀錄。基礎方案專注於語音問答與企業知識庫檢索。

以下功能擴充模組按需求評估加購。呢份文件冇寫模組單價，唔好自己報一個數字：

1. 網頁自動跳轉導航
2. 語音代填表單與互動 UI 操控
3. 專屬品牌真人聲線克隆（提供 1 至 3 分鐘真人錄音樣本）
4. WhatsApp 客資即時推送與雙向接管
5. AI 主動外呼跟進模組（接駁公司 +852 商業電話線；無人接聽不扣分鐘）
6. CRM / 預約系統雙向 API 串接（可包括多品牌知識庫隔離與高可用性架構）

收費頁計算機用現有階梯做每月流量成本試算：首 500 分鐘每分鐘 HK$4.5，跟住去到 2,500 分鐘每分鐘 HK$3.5，超出每分鐘 HK$2.2。呢個只係試算，唔係書面報價。具體專案設定費 HK$8,000 起及所選擴充模組報價，將於免費評估會議確認。訪客問實價，唔好將試算講成已確認月費。

上線時間：以上 3 週為標準網站部署參考週期。實際交付時間會視乎個別客戶嘅網站架構複雜度、企業知識庫資料準備進度，以及是否涉及第三方系統 API 對接而有所調整，顧問團隊將於第 1 週規劃會議確認具體時間表。

安全：嚴格根據客戶上傳嘅 PDF 同官方資料作答，超出範圍轉交真人。每個客戶有獨立加密知識庫，資料唔用於訓練公開 AI 模型。
